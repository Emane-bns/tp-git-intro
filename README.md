# Mon mini-projet Git

## Objectif du projet
Ce projet est une petite page web créée pour apprendre les bases de Git et GitHub.

## Technologies utilisées
- HTML
- CSS
- Git
- GitHub

## Instructions pour ouvrir la page
1. Ouvrir le dossier du projet avec Visual Studio Code.
2. Ouvrir le fichier index.html dans un navigateur web.
